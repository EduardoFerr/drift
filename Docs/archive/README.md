# Docs/archive — planos históricos de fases concluídas

Documentos aqui são **referência histórica**, não documentação ativa.

Cada arquivo descreve o **plano de execução** de uma sub-fase que já
foi entregue. São mantidos pra:

- Auditoria de decisões passadas (por que escolhemos X em vez de Y)
- Onboarding de quem queira entender a evolução do projeto
- Citação em discussões futuras ("essa decisão foi tomada em 6.1b §3")

**Não modificar conteúdo aqui** — se algo precisa de update, abrir
issue/doc novo na raiz de `Docs/`. Estes são snapshots imutáveis.

## Convenção de movimentação

Plano vai pra `archive/` quando:
1. A sub-fase está marcada ✅ no `Docs/fase-6-roadmap.md` (ou equivalente)
2. Decisões críticas do plano foram extraídas pra `drift-arquitetura-v4.md`
   ou `manifesto.md` se relevantes
3. Não há mais "TODOs" abertos no plano que sejam blocker pra próxima fase
