## Decisões de arquitetura desta rodada

### Swipe — pointer events + RAF firmemente estabelecido

A migração V10 (Framer drag → pointer nativos) pareceu pronta em 5555d96
mas revelou edge cases em produção:

| Bug | Causa raiz | Fix | Commit |
|---|---|---|---|
| Double-tap lightbox quebrou | swipeEndAt marcado em qualquer gesto > 8px (jitter de dedo trigger) | Só marcar quando commit efetivo (return bool de commitDecision) | 1548d9a |
| Card "volta" ao centro em swipe horizontal | Border vivia em SwipeHandler wrapper, easeXToZero animava de volta | Mover border/bg pra SubpostCarousel motion.div (slide carrega o card inteiro) | 1548d9a |
| Long-press release sem movimento suprimia click | swipeEndAt marcado mesmo quando dist=0 elapsed>350 | Condicionar em dist > TAP_MAX_DISTANCE_PX | 64cfc6c |
| Long-press não funciona em Portrait/Landscape com imagem | Image lightbox é `<button>` cobrindo inset-0, filter `closest('button')` bailava | Filter mudou pra `closest('a,[data-no-longpress]')`; Image perdeu opt-out, Dots/⋮/"ver mais" ganharam | f9ed28b |
| Up/down alternância exit errado | Exit estático `exit={exitVariant}` congelava snapshot da direção anterior | Variants pattern com função recebendo `custom` da AnimatePresence (lê valor LATEST) | 1e788ab |
| Click fantasma após swipe | `setPointerCapture` não suprime click no target original; iOS/Chrome dispara mesmo assim | `wasSwipeRef` + `onClickCapture` em capture phase + timestamp comparison (race-free) | 5555d96, 85d0176 |
| Card pula mid-animation | pointerdown reset startX sem considerar xRef em curso | Anchor `startX = clientX - xRef/ELASTICITY`, `startXRaw` separado pra tap detection | 0305dea |

### Deep-link — overlay no cursor do feed, sem modal separado

V9.20 renderizava `<PostViewer>` SEM `embedded` prop quando ?p=<nevent>
resolvia — caía em ModalWrapper (visual V7 órfão). User chegando via
share via outro app via "tela igual à primeira versão do app".

V10.9 (30a51b3) integra deepLinkedPost ao `currentPost` useMemo do home
view. Spread/bury limpa overlay; cursor original do feed permanece
intocado. Se post já está no feed, dedup repositioning cursor.

### A11y font-size — 12px é o piso mobile

127 ocorrências de `text-[11px]` viraram `text-[12px]`. Visual delta de
1px imperceptível, mas Lighthouse `font-size` audit saiu de 53% legível
pra 82.71% (passing). Drift-button md size também atualizado em test.

### Lazy de componentes nunca-renderizados-no-boot

Critério Ted (RFC perf round 10 §2.2): demote a lazy se chunk ≥ 15 KB
raw. GpsErrorBanner (9 KB), DialogHost (3.9 KB), UpdatePrompt (3.5 KB)
violam isso tecnicamente, MAS são casos de **dead-on-boot** — nunca
executam no caminho crítico. Entry chunk vai pra eles via lazy() chain
mas o JS deles fica fora do parse inicial. -11.5 KB raw / -4.4 KB gz no
entry, sem custo de round-trip porque não renderizam até evento
específico.
