`gh run list --workflow lighthouse.yml --limit 20` mostra **20 runs
consecutivos `failure` em 3-4s** desde 2026-05-26 00:16 BRT (commit
`6ebf1ca`) até `c059463` (run mais recente, 03:39 BRT).

```
gh run view 26430864586
> The job was not started because recent account payments have failed
> or your spending limit needs to be increased. Please check the
> 'Billing & plans' section in your settings
```

Mesma annotation em **todos os 20** — falha não é técnica, é admin de
billing. Os jobs nem partem do step 1 (`actions/checkout`); failure
imediato no scheduler do GitHub Actions. Logs vazios (`gh run view --log-failed`
retorna `log not found` — nada foi escrito).

bloqueio — nenhum dos 49 commits do Sprint N+3 megarodada foi medido.
O workflow funciona; a conta não funciona.
